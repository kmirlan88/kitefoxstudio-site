Kitefox Uploader Privacy Policy

This policy covers Kitefox Uploader, an internal tool operated by Kitefox Studio LLC (“we”, “us”) in Austin, Texas. It explains what the tool does with data it gets from Google.

YouTube API Services

Kitefox Uploader uses YouTube API Services. Google's handling of your data is described in the Google Privacy Policy, and use of YouTube is governed by the YouTube Terms of Service.

Who this applies to

The tool is used only by Kitefox Studio, on YouTube channels we own. It does not have other users, and it does not collect data from viewers of our videos or from any other channel.

What we access

When we sign in with Google, the tool asks for permission to manage our YouTube account (the youtube.force-ssl scope). With it, the tool:

  • reads our own channel's ID and name, to make sure it is acting on the right channel;
  • uploads our videos and reads and updates their title, description, language, category, audience, AI disclosure, visibility and processing status;
  • sets thumbnails, adds subtitle tracks and adds videos to our playlists.

It does not read comments, subscribers, viewer information, analytics or other people's content, and it never deletes videos.

What we store, and where

  • Sign-in token. Google gives the tool an access token and a refresh token. They are kept only on our own computer, in a folder only our user account can read. They are never sent anywhere except to Google.
  • Release records. For each of our releases, we keep a file with the video's ID, link, the details we set and whether it is public or scheduled. These describe our own videos. The tool refreshes them each time it runs against a video.

We do not use cookies or tracking in the tool, and we do not store any data about other people.

Sharing

We do not sell, rent or share data from YouTube API Services with anyone. The tool sends data only to Google, to perform the actions listed above.

How to revoke access and delete data

Access can be removed at any time in Google Account → Third-party connections (also reachable from Google's security settings). Removing access stops the tool immediately. We delete the stored sign-in token when access is removed, and we delete any stored YouTube API data within 30 days of a request sent to the address below.

Changes

If this policy changes, we will update it here and change the date at the top.
